## 阶段 8：审批任务完整功能（已完成）

完成企业文档审批工作流系统阶段 8，交付审批闭环核心能力：

### 实现内容
1. **资源级授权接入 Controller**：`ApprovalController` 的 Approve/Reject/Return/ReturnToPrevious/Transfer 均通过 `IAuthorizationService.AuthorizeAsync` 加载 `ApprovalTask` 资源，交由 `ApprovalTaskAuthorizationHandler` 做资源级授权，真正审批时二次校验候选人/委托。
2. **审计接入 ApprovalService**：`ApprovalService` 注入 `IAuditService`，提交/审批/驳回/退回/退回上一步/撤回/转交全部写 AuditLog。
3. **会签逻辑**：`ApprovalTask` 新增 `CountersignPercentage`/`RequiredApprovals`/`CompletedApprovals`，`SetCandidates` 按候选人数×比例向上取整计算所需通过人数；`RecordCandidateApproval` 聚合候选人通过并判定节点是否满足阈值。`ApprovalCandidate` 新增 `HasActed`/`ActedStatus`/`ActedAtUtc` 防重复审批。
4. **金额条件分支**：新增 `IApprovalFlowProvider` 抽象 + `BudgetApprovalFlowProvider` 实现（Application 层），按金额折算 CNY 后分支：<1万经理；1-10万经理→部长；≥10万经理→部长→财务→事业部负责人。
5. **多币种汇率**：新增 `ICurrencyService` + `FixedCurrencyService`（固定汇率表，可替换为 ExchangeRate 表/外部源）。
6. **Bookmark 挂起恢复**：`ManagerApprovalStep` 用 `CreateBookmark` 挂起；`ElsaWorkflowService.AdvanceAsync` 用 `IStimulusSender.SendAsync`（含 WorkflowInstanceId）精确恢复单实例。
7. **退回上一步**：`ApprovalTask.ReturnToPrevious()` + `IApprovalService.ReturnToPreviousAsync`，重新创建上一审批步骤任务（中间审批人重新审批）。
8. **代理审批有效期校验**：`EnsureCanActAsync` 二次校验委托规则有效期，过期委托不能审批。

### 关键架构决策
- `BudgetApprovalFlowProvider`、`FixedCurrencyService` 放在 **Application 层**（`WorkflowSystem.Application.Services`），而非 Infrastructure，因它们是纯业务规则（不依赖 EF）。
- `IWorkflowService.AdvanceAsync` 签名改为 `AdvanceAsync(instanceId, completedStepKey)` 返回 `bool`（是否流程结束）。
- Elsa 用 `IStimulusSender`（非过时的 `IWorkflowInbox`）；`StimulusMetadata.WorkflowInstanceId` 精确恢复单实例避免并发误恢复。
